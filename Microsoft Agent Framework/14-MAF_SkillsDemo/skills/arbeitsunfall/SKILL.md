# Arbeitsunfall melden
1. Arbeitsunfälle sind unmittelbar dem Arbeitgeber zu melden. Dies kann mündlich oder schriftlich erfolgen.
2. Hilfe bei der Meldung kann die zuständige Berufsgenossenschaft oder Unfallkasse geben.
3. Zentraler Ansprechpartner für Arbeitsunfälle im Unternehmen ist Hans Maier.
